# Curso DevOps desde cero: CI/CD, contenedores, automatización y SRE para QA y desarrolladores o cualquiera que quiera aprender
## Udemy

¿Quieres aprender DevOps desde cero y dominar las herramientas y prácticas que permiten entregar software de manera rápida, eficiente y confiable? Este curso está diseñado para QA, desarrolladores, SREs y cualquier persona interesada en DevOps, sin necesidad de experiencia previa. Aprenderás paso a paso cómo implementar DevOps en entornos reales, comprendiendo tanto la teoría como la práctica. Este es un curso completo de DevOps donde se aprende a usar todas las herramientas clave del ecosistema, abarcando desde el control de versiones hasta la automatización de despliegues y la orquestación de contenedores.

En este curso descubrirás cómo crear y gestionar pipelines CI/CD, automatizando la integración y entrega de código con herramientas modernas como Git, Docker y Jenkins. Aprenderás a construir, desplegar y administrar contenedores y aplicaciones automatizadas, garantizando entornos consistentes, seguros y reproducibles. Además, dominarás la gestión de configuración, secretos y variables de entorno utilizando Kubernetes, entendiendo cómo separar la aplicación de su configuración y proteger información sensible de manera efectiva.

También aprenderás a aplicar principios de SRE (Site Reliability Engineering) y buenas prácticas para mejorar la colaboración entre desarrollo y operaciones, optimizando la entrega de software y reduciendo errores en producción. Este curso combina ejemplos prácticos, ejercicios reales y explicaciones detalladas, para que puedas aplicar tus conocimientos desde el primer día y consolidar habilidades profesionales aplicables en cualquier proyecto DevOps.
