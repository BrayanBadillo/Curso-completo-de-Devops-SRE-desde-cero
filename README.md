# Curso-completo-de-Devops-SRE-desde-cero
En este curso descubrirás cómo crear y gestionar pipelines CI/CD, automatizando la integración y entrega de código con herramientas modernas como Git, Docker y Jenkins. Aprenderás a construir, desplegar y administrar contenedores y aplicaciones automatizadas, garantizando entornos consistentes, seguros y reproducibles.
